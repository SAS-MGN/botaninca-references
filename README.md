# Base de références BOTANINCA : études sur la maca, le camu camu, la griffe de chat et d'autres plantes

Cette base est publiée par [BOTANINCA](https://botaninca.fr), marque française de compléments alimentaires à base de plantes du Pérou. Elle rassemble les études citées sur le site, avec pour chacune ce qui a été mesuré : population, effectif, durée, type d'étude et critère principal.

## Méthode

Chaque référence est confrontée à sa notice PubMed et, quand il est accessible, au texte intégral. Seules les références dont l'identifiant a été vérifié figurent ici. Quand la notice ne donne pas une valeur, la base l'écrit : « non précisé dans la notice ». Dernière mise à jour : 9 novembre 2026.
